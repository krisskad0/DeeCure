# kb

The knowledge base: plain-English explanations, as YAML. This is what makes DeeCure friendly.

| Folder | Explains | Example file |
| --- | --- | --- |
| `services/` | systemd services | `cups.yaml` |
| `errors/` | Log and kernel errors | `ext4-error.yaml` |
| `ports/` | Network ports | `5432-tcp.yaml` |
| `packages/` | Packages | `snapd.yaml` |

- Format: [Knowledge base](../docs/02-architecture/knowledge-base.md)
- How to add one: [Writing rules and KB entries](../docs/04-development/writing-rules-and-kb.md)
