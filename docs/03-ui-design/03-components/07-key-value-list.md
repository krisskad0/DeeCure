# Key-value list

[Docs](../../README.md) › [UI design](../README.md) › [Components](README.md)

Two-column grid: `minmax(120px, 40%) | 1fr`. Rows padding 7 0, bottom border except the last row. In a flush panel the rows get 14 px left and right padding, so the text lines up with tables and setting rows. Key `--muted`, value `--ink` (wraps anywhere).
