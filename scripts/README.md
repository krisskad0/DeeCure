# scripts

Developer scripts. Each script prints help with `--help`.

| Script (planned) | What it does |
| --- | --- |
| `build-deb.sh` | Build the `.deb` and run `lintian` (used by `make deb`) |
| `bump-version.sh` | Set one version in every manifest |
| `capture-fixture.sh` | Capture test data from this machine, with private data removed |
| `dev-install-helper.sh` | Install dev copies of the helper's D-Bus and polkit files |
| `dev-uninstall-helper.sh` | Remove them again |
